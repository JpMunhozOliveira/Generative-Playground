# Generative Playground

**Um espaço interativo para explorar arte generativa no navegador.**

Crie padrões animados, experimente com sistemas matemáticos e exporte seus resultados favoritos como imagem.

## ✨ Experimentos

Escolha um experimento e ajuste seus parâmetros para explorar diferentes resultados visuais.

| Experimento | Descrição |
|---|---|
| **Mandala** | Gera padrões geométricos animados em camadas. |
| **Sistema de Partículas** | Partículas em movimento que se conectam quando estão próximas. |
| **Padrão de Ruído** | Texturas animadas inspiradas em ruído procedural. |
| **Flow Field** | Milhares de partículas guiadas por um campo de vetores. |
| **Atrator Caótico** | Trajetórias complexas geradas por um sistema caótico (atrator de Clifford). |
| **Curvas Lissajous** | Curvas intrincadas criadas a partir de movimentos periódicos. |
| **Árvore Fractal** | Estruturas ramificadas inspiradas em geometria fractal, balançando ao vento. |
| **Diagrama de Voronoi** | Células que se reorganizam em tempo real conforme as sementes se movem. |
| **Reação-Difusão** | Simulação química de Gray-Scott que gera corais, labirintos e manchas que se dividem como células. |
| **Physarum** | Dezenas de milhares de agentes que, seguindo rastros, formam redes como as de um bolor limoso. |
| **Fractal Julia/Mandelbrot** | Conjunto de Julia em transformação contínua ou zoom infinito no Mandelbrot. |
| **Boids (Revoada)** | Comportamento de bando emergente a partir de separação, alinhamento e coesão. |
| **Jogo da Vida** | Autômatos celulares (Conway, HighLife, Dia e Noite, Labirinto) com rastro das células. |

## 🧰 Funcionalidades

- **Controles interativos** — Altere os parâmetros e veja o canvas atualizar em tempo real.
- **Aleatorizar** — Sorteia uma nova combinação de parâmetros com um clique (ou tecla `R`), com transição animada até os novos valores.
- **Links compartilháveis** — Os parâmetros ficam na URL; copie o link e qualquer pessoa abre exatamente a mesma configuração.
- **Exportação em PNG** — Salve o canvas atual como imagem, na resolução nativa da tela.
- **Atalhos de teclado** — `Espaço` pausa/continua, `R` aleatoriza, `Esc` fecha o modal.
- **Direto no navegador** — Nenhuma instalação ou software adicional é necessário para usar a demo.

## 🛠️ Tecnologias

- **HTML5** — Estrutura da aplicação.
- **CSS3** — Layout e estilo visual.
- **JavaScript (ES Modules)** — Lógica dos experimentos e comportamento da aplicação.
- **HTML Canvas API** — Renderização em tempo real dos visuais generativos.

## 🚀 Rodando localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/JpMunhozOliveira/Generative-Playground.git
   ```

2. Abra a pasta do projeto no seu editor.
3. Inicie um servidor de desenvolvimento local. ES modules funcionam melhor servidos via HTTP do que abertos diretamente com `file://`.
4. Abra a URL local informada pelo servidor.
