# Generative Playground

**An interactive space for exploring generative art in your browser.**

Create animated patterns, experiment with mathematical systems, and export your favorite results as images.

[🌐 Live Demo](https://jpmunhozoliveira.github.io/Generative-Playground/) · [📦 Repository](https://github.com/JpMunhozOliveira/Generative-Playground)

## ✨ Experiments

Choose an experiment and adjust its parameters to explore different visual results.

| Experiment | Description |
|---|---|
| **Mandala** | Generate animated, layered geometric patterns. |
| **Particle System** | Explore moving particles and the connections between them. |
| **Noise Pattern** | Create animated textures inspired by procedural noise. |
| **Flow Field** | Explore flowing motion and patterns guided by a field. |
| **Chaotic Attractor** | Visualize complex trajectories generated by chaotic systems. |
| **Lissajous Curves** | Create intricate curves from periodic motion. |
| **Fractal Tree** | Generate branching structures inspired by fractal geometry. |
| **Voronoi Diagram** | Explore cell-like patterns built from Voronoi regions. |

## 🧰 Features

- **Interactive controls** — Change experiment parameters and see the canvas update in real time.
- **Multiple generative systems** — Switch between eight visual experiments.
- **PNG export** — Save the current canvas as an image.
- **Browser-based** — No installation or additional software is required to use the live demo.

## 🛠️ Technologies

- **HTML5** — Application structure.
- **CSS3** — Layout and visual styling.
- **JavaScript (ES Modules)** — Experiment logic and application behavior.
- **HTML Canvas API** — Real-time rendering of generative visuals.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/JpMunhozOliveira/Generative-Playground.git
   ```

2. Open the project folder in your editor.
3. Start a local development server. JavaScript ES modules work best when served over HTTP rather than opened directly with `file://`.
4. Open the local URL provided by your server.
