# Generative Playground

An interactive playground for experimenting with generative art using JavaScript and the HTML Canvas API.

🌐 **[Open the live demo](https://jpmunhozoliveira.github.io/Generative-Playground/)**

## Features

- **Mandala** — Create animated geometric patterns and adjust petals, layers, rotation speed, line width, and color.
- **Particle System** — Explore moving particles and their connections by adjusting particle count, speed, connection distance, and color.
- **Noise Pattern** — Generate animated noise-inspired visuals with adjustable scale, complexity, speed, and color palettes.
- **PNG Export** — Save the current canvas as an image.
- **Real-time Controls** — Change experiment parameters and see the results immediately.

## Built With

- HTML5
- CSS3
- JavaScript (ES Modules)
- HTML Canvas API

## Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/JpMunhozOliveira/Generative-Playground.git
   ```
2. Open the project folder.
3. Serve the files using a local web server, since the project uses JavaScript ES modules.
4. Open the local address provided by your server in a browser.
